Todo lo que necesitas para configurar tu catálogo, armar kits y mantener el control exacto de tu stock desde el primer día.

📦

Tu Catálogo de Productos

Configura cada artículo una sola vez y utilízalo en ventas, compras, traspasos y reportes.

  1. 1

    Accede al módulo de Artículos

    Inventario › Artículos › + Nuevo Artículo

    Desde el menú principal ve a Inventario → Artículos. Haz clic en el botón + Nuevo para abrir el formulario de alta.

  2. 2

    Asigna un nombre y código interno

    El nombre es lo que verán tus clientes en cotizaciones y facturas. El código interno (SKU) es el identificador único dentro del sistema — puede ser tu referencia de proveedor, código de barras, o la clave que ya manejas.

    Nombre
    Laptop Lenovo 15"
    Código interno (SKU)
    LEN-THK-15-001
    Código de barras
    7501234567890
    Categoría
    Equipo de cómputo

    Si aún no tienes un código, puedes dejar que el sistema genere uno automático al guardar.

  3. 3

    Elige el tipo de artículo

    El tipo determina cómo el sistema registra movimientos de stock y costos.

    📦 Inventariable

    Inventario

    Producto físico que ocupa espacio en almacén. El sistema registra entradas, salidas y saldo disponible.

    • Laptops, insumos, repuestos
    • Materia prima
    • Mercancía para reventa
    ⚡ No inventariable

    Servicio

    Trabajo o servicio intangible. No genera movimientos de stock ni requiere almacén.

    • Instalación, mano de obra
    • Consultoría, diseño
    • Garantías extendidas
    💡
    ¿Cuál elegir?

    Regla simple: si lo recibes en un almacén y lo puedes contar físicamente, es tipo Inventario. Si lo prestas con tiempo y persona, es tipo Servicio.

  4. 4

    Define precios y costos

    Establece el precio de venta base que aparecerá en cotizaciones. El costo se actualiza automáticamente con cada recepción de compra, pero puedes capturarlo manualmente si es el primer artículo.

    IVA 16%
    Unidad de medida
    Pieza
  5. ✓

    Guarda y verifica el artículo

    Haz clic en Guardar. El artículo aparecerá en tu catálogo y ya podrás seleccionarlo en cotizaciones, órdenes de compra y traspasos.

    ✅
    Carga masiva disponible

    Si tienes más de 20 artículos, usa la importación desde Excel en Artículos → Importar. Descarga la plantilla, llena las columnas y súbela — el sistema valida duplicados automáticamente.

Kits y Recetas (BOM)

Agrupa productos en paquetes o define la lista de materiales (Bill of Materials) para artículos de ensamble.

  1. 1

    Crea el artículo padre (el kit)

    Inventario › Artículos › Nuevo Kit

    Primero da de alta el artículo resultante — por ejemplo "Equipo de escritorio armado". Márcalo como tipo 🧩 Kit / BOM en el campo de tipo.

    Este artículo es el que aparecerá en cotizaciones y facturas como un solo renglón con su precio total.

  2. 2

    Agrega los componentes (líneas de receta)

    Dentro del artículo kit, abre la pestaña Componentes (BOM) y agrega cada parte con su cantidad requerida:

    Componente
    Cantidad
    Costo unitario

    1 set

    Cable HDMI 2m
    2 pzas

    Puedes buscar componentes por nombre o código SKU. Solo artículos de tipo Inventario o Servicio pueden ser componentes de un kit.

  3. 3

    Aplica precios automáticamente

    Una vez que tienes todos los componentes, el sistema puede calcular el precio sugerido del kit sumando los costos. Haz clic en:

    💲 Aplicar Precios

    Esto actualiza el campo de costo total del kit con la suma de los componentes. Puedes mantener ese costo como referencia y ajustar el precio de venta manualmente con tu margen.

    ⚠️
    Precio de venta vs. costo calculado

    El botón "Aplicar Precios" solo actualiza el costo del kit — no sobreescribe el precio de venta que definas. Ajusta el precio de venta por separado con el margen que necesites.

  4. ✓

    Guarda y prueba en una cotización

    Al guardar el kit, el sistema descuenta stock de cada componente individualmente cada vez que se vende el kit. Pruébalo creando una cotización con el artículo kit — verás un solo renglón con precio total y en el detalle de almacén se reflejarán los movimientos de cada pieza.

    💡
    Kits sin stock

    Si algún componente no tiene existencia disponible, el sistema te avisará al intentar facturar. Puedes configurar si deseas bloquear la venta o solo mostrar una advertencia desde Configuración → Inventario → Alertas de stock.

  1. 1

    Consulta el saldo actual por artículo

    Inventario › Existencias

    La vista de Existencias muestra el saldo en tiempo real de cada artículo por almacén. Filtra por categoría, almacén o rango de stock para localizar rápidamente artículos bajo mínimo.

  2. 2

    Realiza un ajuste de inventario

    Inventario › Movimientos › + Ajuste

    Cuando el conteo físico no coincide con el sistema, crea un Ajuste de Inventario. Captura la cantidad real contada — el sistema calcula automáticamente la diferencia y registra el movimiento con fecha, usuario y motivo.

    ⚠️
    Los ajustes afectan costos

    Un ajuste negativo reduce tu activo en inventario. Si la diferencia es grande, consulta con tu contador antes de aplicar — algunos ajustes requieren una póliza contable de respaldo.

  3. 3

    Transfiere stock entre almacenes

    Inventario › Traspasos

    Para mover mercancía de un almacén a otro (por ejemplo, de bodega central a sucursal), crea un Traspaso. Selecciona el almacén de origen, el destino, los artículos y las cantidades. El sistema actualiza ambos saldos al confirmar.

  4. ✓

    Configura alertas de stock mínimo

    Define el punto de reorden en cada artículo para recibir notificaciones automáticas cuando el stock baje del umbral. Ve a Artículos → editar artículo → pestaña Almacén y establece el valor en el campo Stock mínimo.

    💡
    Reorden automático

    Si conectas un proveedor predeterminado a cada artículo, UniSuite puede sugerir una orden de compra automáticamente cuando el stock baje del mínimo. Actívalo en Configuración → Compras → Reorden automático.
